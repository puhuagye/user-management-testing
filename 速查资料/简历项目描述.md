### 版本一：项目经验型（推荐，适合应届生/实习简历）

**项目描述：**
独立搭建 Linux + MySQL + Flask 被测环境，设计 RESTful API 并对用户增删改查进行接口测试；基于 Selenium 编写 UI 自动化用例，采用 Page Object 模式，实现 UI → 接口 → 数据库三层校验的端到端自动化测试体系。

**技术栈：** Python / Flask / MySQL / Pytest / Requests / Selenium / PyMySQL / YAML

**主要工作：**
1. 使用 Flask + PyMySQL 搭建被测系统，设计 5 个 RESTful 接口（CRUD）和 3 个 HTML 前端页面
2. 编写 13 条接口自动化测试用例（Pytest + Requests），覆盖正常与异常场景，包含参数化测试和数据库落地校验
3. 编写 8 条 Selenium UI 自动化用例，采用 Page Object 模式封装页面元素与操作，实现 UI 层、接口层、数据库层三层校验
4. 使用 Pytest fixture 管理测试生命周期，yield 机制实现测试数据自动清理，pytest-html 生成测试报告
5. 使用 YAML 统一管理项目配置，设计环境变量覆盖机制支持多环境切换
6. 使用 Git 进行版本管理，README 编写项目文档

### 版本二：工作职责型（适合"工作经历"栏，强调你会什么）

- 负责用户管理系统 5 个 RESTful API 的接口自动化测试，编写 13 条测试用例，覆盖增删改查正常流程及异常场景（缺参数、空请求体、资源不存在等）
- 使用 PyMySQL 直连 MySQL 数据库进行数据落地校验，确保接口返回与数据库实际状态一致
- 基于 Selenium WebDriver 编写 8 条 UI 自动化用例，采用 Page Object 设计模式，将页面元素定位与操作封装成独立的类，降低代码维护成本
- 引入 Pytest fixture 管理测试前置与后置（数据库连接、HTTP session、测试数据清理），实现测试数据零残留
- 使用 YAML 文件集中管理项目配置（数据库、被测地址、应用参数），通过环境变量实现多环境配置覆盖
- 21 条 API + UI 测试一条命令执行完毕，pytest-html 自动生成可视化测试报告
